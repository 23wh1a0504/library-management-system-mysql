# Library Management System (MySQL)

This project demonstrates a relational database design for managing
books, members, and borrowing records in a library using MySQL.

## Features
- Store book information
- Manage library members
- Track borrowed and returned books
- Generate reports using SQL queries

## Database Tables
1. Members
2. Books
3. Borrowed_Books

## Technologies Used
- MySQL
- SQL
